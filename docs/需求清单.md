## 一、系统概述

捷控云盒（一体机）是面向低空政务航空场景的私有化部署设备，内置两套系统：

| 系统 | 定位 | 本清单范围 |
|------|------|-----------|
| **运维中心** | 设备激活、配置、升级、备份还原、监测、重置等运维管理 | ✅ 本清单全部功能 |
| **翼飞平台**（政务航空平台） | 业务应用：业务中台、指挥调度、飞控中心、对比标注、事件处置、建图采集、接警侦察 | ⛔ 不在本期范围，仅作为对接对象（见第五章） |

**用户角色**

| 角色 | 说明 |
|------|------|
| 运维管理员 | 登录运维中心，默认账号 `admin`，首次登录须修改初始密码 |
| 项目管理员 | 在「项目信息配置」中设置，用于登录翼飞平台（超级管理员） |

**版本差异**

| 项目 | 标准版 | 超脑版（本期） |
|------|--------|---------------|
| 机场授权数量 | 4 台，不限时间 | 10 台，不限时间 |
| 内置能力 | 基础服务 | 11.52TB 存储、直播（无流量限制）、标配 AI 3 路并发、二维建图/三维建模算图服务 |

## 三、功能需求清单

> 列说明：**控标描述**取自控标表原文要点；**操作细节**取自操作手册；**优先级** P0=核心必备 / P1=重要 / P2=一般。

### M00 登录

| 编号 | 功能 | 需求描述 | 优先级 |
|------|------|---------|--------|
| F00-01 | 运维中心登录 | 输入账号密码登录运维中心；默认账号 `admin`；登录成功后进入功能入口页；支持本机显示器访问与同网段电脑远程访问（`http://<设备IP>:40001/`） | P0 |

### M01 激活模块（首次激活向导，6 步）

按顺序完成 6 个步骤即完成激活；激活完成后激活入口不再展示，后续变更走「配置模块」，需回到初始状态走「重置模块」。

| 编号 | 功能 | 控标描述 | 操作细节 | 优先级 |
|------|------|---------|---------|--------|
| F01-01 | 网络信息配置（第 1 步） | 支持自动获取 IP 配置，选择内网/互联网模式，上传 SSL 证书 | ① 自动获取 IP、子网掩码、网关、DNS1、DNS2，可手动修改，可点击「获取最新IP」重新获取；② 选择翼飞平台登录模式：**互联网模式**须填访问地址（不得含特殊字符）和端口，须上传 SSL 证书，并提示需开通的端口映射清单（见 6.2）；**内网模式**按 IP 自动生成地址，默认端口 443，可修改；③ 上传 SSL 证书，不上传则使用系统默认证书；④ 保存后进入下一步 | P0 |
| F01-02 | 设备激活配置（第 2 步） | 标准版 4 台 / 超脑版 10 台机场授权，不限时间 | 展示授权开始时间、结束时间、设备授权数量，确认后进入下一步 | P0 |
| F01-03 | 基础服务配置（第 3 步） | 存储/通信/视频/时序服务支持内置配置或自定义；存储支持独立 MinIO 与 OSS；可按路由和机场 IP 设置端口与密码 | 四项服务默认「内置配置」，无特殊要求直接下一步；选择自定义时展示对应参数表单（字段见 F02-03） | P0 |
| F01-04 | 项目信息配置（第 4 步） | 集中配置项目名称、类型、管理员账号与密码、所属项目中心，可选短信接收语言 | 填写项目名称、管理员账号、管理员密码、项目类型、项目中心、短信语言；用于翼飞平台项目名称展示和超级管理员账号 | P0 |
| F01-05 | 可选服务配置（第 5 步） | AI识别、二维建图、三维建模、AI比对服务的启停；AI识别/二维建图/AI比对支持云端或本地自建 GPU；三维建模仅支持云端，按需采购 | 可不选直接下一步；**云端服务**须填写《云端资源授权码》；**本地服务**须填写对应参数（字段见 F02-05） | P1 |
| F01-06 | 系统初始化（第 6 步） | 根据配置一键初始化 | ① 点击「开始系统初始化」→ 二次确认 → 执行；② 实时展示各服务初始化进度；③ 完成后展示**应用平台地址**、**运维中心地址**、**设备上云信息（MQTT）**，均支持复制，应用平台地址支持点击跳转；④ 点击关闭完成激活 | P0 |

### M02 配置模块（配置修改向导，6 步）

激活后用于查看/修改配置。**任何修改须执行第 6 步「重启服务」才生效**，页面需给出该提示。

| 编号 | 功能 | 控标描述 | 操作细节 | 优先级 |
|------|------|---------|---------|--------|
| F02-01 | 网络信息配置 | 自动获取 IP、修改 SSL 证书、修改访问模式和访问地址，提示互联网模式需开通的端口 | 修改 IP 保存后当前登录地址随之变更（需提示）；支持更新过期 SSL 证书；支持模式/地址切换（如域名未下来时临时用 IP） | P0 |
| F02-02 | 设备激活配置 | 查看当前授权额度和授权时间 | **只读**，不支持修改或解绑；需修改时提示走重置 | P1 |
| F02-03 | 基础服务配置 | 同 F01-03 | **存储服务**（存放机场图片、视频）：类型 MinIO / OSS；OSS 字段：文件过期时间（STS 时效，默认 36000）、存储桶名称、EndPoint 地址、CDN 地址、角色 ARN、角色会话名称、区域、AccessKeyId、AccessKeySecret；**通信服务**（机场上云）：账户名、账户密码、wssUrl、服务内部 tcpUrl，修改后需提示机场重新上云；**视频服务**（直播）：地址端口、密钥、应用名称、回放地址、推流服务地址；**时序服务**：自定义参数 | P0 |
| F02-04 | 项目信息配置 | 设置项目名称、管理员账号、管理员密码、项目中心 | 可修改除**项目ID**外的全部字段（项目名称、管理员账号/密码、项目类型、项目中心） | P1 |
| F02-05 | 可选服务配置 | 四项服务的开启/关闭及本地/云端切换 | 展示云端额度，额度不足提示联系商务；算法数量可点击查看算法详情；本地服务字段：**AI识别**＝服务器地址、用户名、密码、回调地址；**二维建图**＝服务器地址、用户名、密码、节点信息；**AI比对**＝服务器地址、回调域名；**三维建模**仅云端 | P1 |
| F02-06 | 重启服务 | 一键使配置生效 | 点击「重启服务」→ 二次确认 → 执行并展示结果；未重启则提示修改未生效 | P0 |

### M03 升级模块

入口在功能入口页；存在可升级版本时显示提醒标识。分**运维中心**、**翼飞平台**两个对象，各自支持在线/本地两种方式。

| 编号 | 功能 | 需求描述 | 优先级 |
|------|------|---------|--------|
| F03-01 | 运维中心在线更新 | 自动检测待更新版本并提醒；展示版本介绍；下载增量更新包 → 执行更新 → 自动校验、安装；更新中可查看更新对应的服务内容；失败自动回滚；成功后标记为「当前版本」；生成带时间戳的更新日志，支持查看 | P0 |
| F03-02 | 运维中心本地更新 | 展示当前版本号（用于发给商务获取升级包）；通过本地文件/U盘导入升级包 → 自动版本校验、依赖检测 → 一键升级；支持更新前后执行自定义脚本；记录操作日志 | P0 |
| F03-03 | 翼飞平台在线更新 | 同 F03-01，对象为翼飞平台 | P0 |
| F03-04 | 翼飞平台本地更新 | 同 F03-02，对象为翼飞平台 | P0 |

## 四、核心业务流程

```
开机 → 登录运维中心(admin) → 首次修改密码
     → 【激活】网络 → 授权 → 基础服务 → 项目信息 → 可选服务 → 初始化
     → 获得 应用平台地址 / 运维中心地址 / 设备上云信息
     → 登录翼飞平台：录入机场 → 机场上云 → 调试 → 航线 → 计划

日常运维：配置修改 → 重启服务生效 ｜ 升级 ｜ 备份/还原 ｜ 服务监测
故障处理：备份 → 重置 → 重新激活 → 导入还原
```

## 六、非功能需求

### 6.1 部署与环境
- 支持互联网、内网、专网、4G/5G 移动网络；优先有线网络，暂不兼容 WiFi
- 即插即用，无需专业机房与专业运维，约 10 分钟完成部署
- 访问方式：本机显示器 或 同网段电脑浏览器远程访问

### 6.2 互联网模式端口映射（需在页面中提示）

| 内部端口 | 协议 | 用途 |
|---------|------|------|
| 443 | TCP | 平台页面 |
| 1883 | TCP | 无人机通讯接口 |
| 9000 | TCP | 素材管理 |
| 11935 | TCP | 直播数据推流 |
| 18000 | TCP | 直播数据拉流（映射端口须与内部端口一致） |

### 6.3 安全
- 首次登录强制修改默认密码
- 密钥、密码类字段（AccessKeySecret、服务密码等）页面掩码展示，接口返回脱敏
- 重置、重启服务、初始化、还原等高危操作必须二次确认
- 升级、备份、还原、重置、重启等操作全部记录带时间戳的日志

### 6.4 可靠性
- 升级失败自动回滚
- 备份保留最近 5 份
- 内网模式须使用 https 访问翼飞平台，直接 http IP 访问会导致部分资源无法加载（页面需提示）
