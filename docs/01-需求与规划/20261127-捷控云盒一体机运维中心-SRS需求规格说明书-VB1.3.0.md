## 二、项目概述

### 2.1 项目背景

捷控云盒（一体机）是面向低空政务航空场景的私有化部署设备，内置「运维中心」和「翼飞平台」两套系统。设备交付到客户现场后，面临以下挑战：

1. **部署门槛高**：客户现场通常没有专业机房和专职运维人员，网络、存储、通信、视频等基础服务需要逐项配置，配置错误会导致平台无法访问或机场无法上云。
2. **网络环境多样**：客户可能处于互联网、内网、专网或 4G/5G 移动网络环境，访问地址、端口映射和 SSL 证书的要求各不相同，需要在配置时给出明确指引。
3. **版本维护困难**：运维中心和翼飞平台都需要持续升级，无网环境下只能通过本地升级包更新，升级失败需要能够回滚，避免业务中断。
4. **数据安全风险**：飞行数据和成果数据是客户的核心资产，重置、迁移设备或故障恢复时需要可靠的备份与复原手段。
5. **运行状态不透明**：设备硬件负载和各业务服务的运行状态无法直观查看，出现故障时难以快速定位和恢复。

为解决上述问题，建设捷控云盒（一体机）运维中心，以向导方式完成设备激活，并集中提供配置、升级、备份、复原、监测和重置能力，实现设备即插即用、约 10 分钟完成部署，降低客户运维成本。

### 2.2 项目建设目标

本项目旨在建设一套随一体机交付的私有化运维管理系统，实现以下目标：

1. **向导式激活**：通过网络信息、设备激活、基础服务、项目信息、可选服务、系统初始化 6 个步骤完成首次激活，每步即时校验，完成后输出应用平台地址、运维中心地址和设备上云信息，客户无需专业知识即可上线。
2. **可控的配置变更**：激活后沿用同一套 6 步页面修改配置，所有修改暂存，执行「重启服务」后统一生效，避免改一半导致服务不可用。
3. **安全的版本升级**：运维中心和翼飞平台分别支持在线升级与本地升级，升级前自动校验版本与依赖，失败自动回滚，全过程记录日志。
4. **完整的数据保护**：支持自动备份与手动备份，保留最近 5 份备份；支持一键还原和导入还原，满足重置后恢复和跨设备迁移。
5. **透明的运行监测**：实时展示 CPU、内存、存储、网络等硬件指标和各业务服务状态，支持一键重启服务和下载日志。

### 2.3 项目建设范围

本项目建设范围包括：

**系统端**：
- 运维中心 Web 端：在一体机本机显示器访问，或在同网段电脑浏览器通过 `http://<设备IP>:40001/` 访问。
- 不建设移动端（待确认，见附录C）。

**功能模块**：
- 登录：账号密码登录运维中心，首次登录修改初始密码。
- 首页（功能入口页）：按设备激活状态和任务状态展示各功能入口。
- 激活 / 配置：6 步向导完成首次激活；激活后入口变为「配置」，用于修改配置并重启服务。
- 升级：运维中心、翼飞平台的在线升级与本地升级。
- 备份：自动备份、手动备份及备份记录管理。
- 复原：一键还原、导入还原。
- 服务监测：硬件指标、服务状态、一键重启、日志下载。
- 项目信息：查看系统登录网址、设备上云信息、云端资源额度、设备授权额度。
- 重置：恢复出厂设置。
- 个人中心：修改密码。
- 国际化语言：界面语言切换。

**数据范围**：
- 配置数据：网络、授权、基础服务、项目信息、可选服务配置。
- 业务数据：基础数据、飞行数据、成果数据（用于备份与复原）。
- 运行数据：硬件指标、服务状态、升级记录、备份记录与各类操作日志。

**不包含的功能**：
- 翼飞平台的业务功能（业务中台、指挥调度、飞控中心、对比标注、事件处置、建图采集、接警侦察），本期仅作为对接对象。
- 设备物理按键触发恢复出厂，由硬件侧实现，软件不实现。
- 靓马云端服务（AI识别、二维建图、三维建模、AI比对）本身，本期只负责授权码验证与额度展示。

### 2.4 业务流程图

> 流程图图片（`images/business-flow.png`）待生成，先以文字流程说明。

```
【首次部署】
设备开机 → 登录运维中心（admin） → 修改初始密码
  → 激活：网络信息 → 设备激活 → 基础服务 → 项目信息 → 可选服务 → 系统初始化
  → 获得 应用平台地址 / 运维中心地址 / 设备上云信息
  → 登录翼飞平台：录入机场 → 机场上云 → 调试 → 航线 → 计划

【日常运维】
配置：修改任一步配置 → 保存 → 重启服务后生效
升级：检测到新版本（首页红点） → 在线升级或本地升级 → 校验 → 安装 → 失败自动回滚
备份：自动备份（定时）/ 手动备份 → 保留最近 5 份
监测：随时查看硬件指标与服务状态 → 异常时重启服务 / 下载日志
IP 变更：首页提醒 → 获取最新 IP → 配置第 1 步 → 重启服务

【故障恢复 / 设备迁移】
备份 → 重置（恢复出厂） → 重新激活 → 一键还原 或 导入还原
```

### 3.5 功能详细设计

### 3.5.1 登录

#### （一）功能需求概述

运维管理员通过账号密码登录运维中心。运维中心可从同网段电脑远程访问，因此登录需防止暴力猜测密码；使用出厂初始密码登录时引导修改密码，保障设备安全。

#### （二）功能设计

**登录表单**

| 字段名称 | 类型 | 长度限制 | 必填 | 默认值 | 说明 |
|---------|------|---------|------|-------|------|
| 账号 | 文本输入 | 1–32 个字符，超出后不能再输入 | 是 | 空；记住密码有效时自动填入 | 提示文字「请输入账号」。只能输入字母、数字、下划线，不区分大小写，提交时自动去掉首尾空格。默认账号 admin |
| 密码 | 密码输入 | （待确认） | 是 | 空；记住密码有效时自动填入 | 提示文字「请输入密码」。默认密文，点小眼睛切换明文或密文。初始密码出厂固定 |
| 记住密码 | 勾选 | - | 否 | 不勾选 | 勾选并登录成功后，7 天内打开登录页自动填入账号和密码；取消勾选后登录即清除 |
| 语言 | 单选 | - | - | 中文 | 中文 / English / ภาษาไทย / Indonesia |

**登录**

点击「登录」，或在账号、密码输入框按回车提交。

- 登录成功（已修改过密码）：进入首页。
- 登录成功（使用初始密码）：进入首页并自动打开「修改密码」窗口。不强制修改，关闭窗口后可正常使用各功能。
- 登录成功后错误次数清零。

**业务规则**

- 账号为空时，失焦或点击登录时阻止提交，账号输入框提示错误，提示「请输入账号」；重新输入后提示消失。
- 密码为空时，失焦或点击登录时阻止提交，密码输入框提示错误，提示「请输入密码」。
- 账号不存在或密码错误时统一提示，不区分两种情况，防止有效账号被逐个试出，错误次数加 1，提示「账号或密码错误，还可尝试 N 次」（N = 5 − 已错次数）。
- 连续错误满 5 次锁定 10 分钟。锁定期间登录按钮不可用，提示「账号已锁定，请 X 分钟后再试」（X 为剩余分钟，向上取整）；到期自动解锁，次数清零。
- 记住密码只保存加密的登录凭证，不保存明文密码，有效期 7 天。
- 切换语言后，页面文字、提示文字、错误提示同步切换。

**边界与异常**

- **第 5 次输错**：直接锁定，不提示「还可尝试 0 次」。
- **锁定期间点击登录**：不响应，继续显示锁定提示。
- **记住密码超过 7 天**：不再自动填入。
- **输入非法字符**：账号中字母、数字、下划线以外的字符输入不进去。

- 依赖个人中心：修改密码成功后，以新密码校验登录，不再触发首次登录改密。
- 依赖重置模块：恢复出厂后账号密码回到初始状态（待确认）。

### 3.5.2 首页

#### （一）功能需求概述

首页是登录后的功能入口页，按设备激活状态和当前任务状态（升级中、复原中）控制各模块能否进入，并集中给出升级提醒、全局状态提示和 IP 变更提醒，避免在不合适的时机执行冲突操作。

#### （二）功能设计

**查看功能入口**

- 页头显示系统名称「运维中心」、当前登录账号和语言切换。
- 展示 7 个功能入口：激活（激活后变为「配置」，位置不变）、升级、备份、还原、服务监测、项目信息、重置。
- 激活状态以服务端返回为准，每次进入首页重新获取。

**进入功能模块**

各入口在不同状态下的可用规则：

| 入口 | 未激活 | 已激活·空闲 | 升级中 | 导入复原中 |
|-----|-------|-----------|-------|-----------|
| 激活 | 显示，可进入 | 不显示 | 不显示 | 不显示 |
| 配置 | 不显示 | 可进入 | 不可用 | 不可用 |
| 升级 | 不可用 | 可进入 | 可进入，查看进度 | 不可用 |
| 备份 | 不可用 | 可进入 | 不可用 | 不可用 |
| 还原 | 不可用 | 可进入 | 不可用 | 可进入，查看进度 |
| 服务监测 | 可进入 | 可进入 | 可进入 | 可进入 |
| 项目信息 | 不可用 | 可进入 | 可进入（只读） | 可进入（只读） |
| 重置 | 不可用 | 可进入 | 不可用 | 不可用 |

- 服务监测在任何状态下都可进入，包括未激活、升级中、备份中、复原中、重置中，用于随时查看服务是否正常。
- 未激活时点击不可用的入口，提示「请先完成激活」。
- 升级中点击不可用的入口，提示「[平台名称]系统正在更新中，请稍后再试」，平台名称为「翼飞平台」或「运维中心」。
- 导入复原中点击不可用的入口，提示「导入复原中，请稍后再试」。
- 复原或升级结束后，入口自动恢复。

**升级提醒**

运维中心或翼飞平台有可更新版本时，「升级」入口显示红点；升级完成、已是最新版本后红点消失。

**系统状态提示**

| 场景 | 全局提示原文 |
|-----|------------|
| 升级中 | 「[平台名称]系统正在更新中」 |
| 一键还原进行中 | 「导入复原中，复原会占用服务，建议您在此期间不再使用翼飞平台」 |

**IP 变更提醒**

- 适用场景：设备已激活并已保存 IP，之后设备重启或更换位置导致 IP 变化。
- 触发条件：IP 在每次开机后重新获取。进入首页时，检测到的 IP 与上次保存的不一致，自动提醒。只在已激活状态下检测。
- 提醒内容：「检测到您的云盒设备已经变更位置，对应的ip地址已经发生变化，请您前往处理。」，并显示「上次保存的IP：」和「当前检测到的IP：」。
- 点击「取消」或 ✕：关闭提醒，本次不处理；下次进入首页仍不一致时再次提醒。
- 点击「获取最新ip」：进入配置第 1 步「网络信息配置」，自动填入最新 IP；用户按配置流程走到第 6 步「重启服务」，重启完成后新 IP 生效。

**账号菜单与退出登录**

- 显示当前登录账号，点击展开菜单，再次点击或点击空白处收起。
- 菜单项「修改密码」：打开修改密码窗口，见 3.5.10。
- 菜单项「退出登录」：清除登录状态，返回登录页（是否二次确认见附录C）。

**边界与异常**

- **升级与复原同时发生**：以哪种状态的提示和不可用规则为准，见附录C。
- **备份中、重置中**：其他入口是否不可用，原型未说明，见附录C。

#### （三）业务逻辑关联

- 依赖激活模块提供激活状态；依赖升级模块提供「是否有可更新版本」「是否更新中」；依赖复原模块提供「是否复原中」。
- IP 变更提醒依赖配置第 1 步保存的 IP 与开机后获取的当前 IP，处理流程复用配置向导。
- 重置完成后激活状态回到未激活，首页入口随之变化。

### 3.5.3 激活 / 配置

#### 3.5.3.0 向导总体说明

**向导结构**：共 6 步，依次为 1 网络信息配置 → 2 设备激活配置 → 3 基础服务配置 → 4 项目信息配置 → 5 可选服务配置 → 6 系统初始化（配置模式下为「重启服务」）。

**两种模式的差异**

| 维度 | 激活模式（首次激活） | 配置模式（激活后修改） |
|-----|-------------------|--------------------|
| 入口 | 首页「激活」 | 首页「配置」 |
| 页面标题 | 初始化 | 配置 |
| 第 6 步名称 | 系统初始化 | 重启服务 |
| 第 1 步提示 | 不显示 | 「IP 或平台访问网址变更后，需要走到第六步「重启服务」并完成重启，修改才能生效。」 |
| 第 2 步 | 未验证时显示「下载激活文件 + 上传授权文件」；已验证通过则直接展示激活信息 | 不提供上传，只读展示激活信息 |
| 第 3 步提示 | 不显示 | 四个服务各显示一条谨慎修改提示 |
| 第 3 步初始值 | 暂存值，否则为默认值 | 暂存值；重新进入时显示系统正在运行的值 |

**返回确认（各步共用）**

点击【返回】需二次确认：「您当前的修改内容未重启、未激活，若返回则不会保存，是否继续返回？」
- 继续返回：放弃本次修改，回到首页。
- 继续填写：关闭确认，已填内容保留。

**暂存规则**：第 1–5 步点「下一步」只暂存数据，第 6 步执行完成后才真正保存并生效。

#### 3.5.3.1 网络信息配置（第 1 步）

##### （一）功能需求概述

配置设备的网络参数和平台访问网址，作为后续服务地址、上云地址的来源；互联网模式下提示所需的端口映射。

##### （二）功能设计

**字段**

| 字段名称 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
|---------|------|---------|------|-------|------|
| IP | 文本输入 | IPv4，每段 0–255 | 是 | 空 | 可通过「获取IP」填入 |
| 子网掩码 | 文本输入 | IPv4 | 是 | 空 | 同上 |
| 网关 | 文本输入 | IPv4 | 是 | 空 | 同上 |
| DNS1 | 文本输入 | IPv4 | 是 | 空 | 同上 |
| DNS2 | 文本输入 | IPv4 | 否 | 空 | 有值时校验格式；不参与获取 IP |
| 平台访问网址-前缀 | 固定文本 | - | - | https:// | 不可编辑 |
| 平台访问网址-访问地址 | 文本输入 | 域名或 IP | 是 | 空 | 字母、数字、中划线，按点分段，每段首尾不能是中划线 |
| 平台访问网址-端口 | 文本输入 | 1–65535 整数 | 是 | 443 | 可修改 |
| 域名SSL证书（公钥） | 文件上传 | 1 个，.pem / .crt | 否 | 空 | 不上传时采用默认证书 |
| 域名SSL证书（私钥） | 文件上传 | 1 个，.key | 否 | 空 | 同上 |

**获取IP**

- 只能手动点击触发，获取中按钮显示「获取中…」且不可再点。
- 成功：填入 IP、子网掩码、网关、DNS1，提示「已获取 IP、子网掩码、网关和 DNS1，可直接修改」。获取结果覆盖已填写的值。
- 失败：提示「当前无法获取对应的 IP、子网掩码、网关和 DNS1 数据，请手动填写」。

**端口清单**

平台访问网址下方提示「当您使用互联网模式时，需要您的路由开通对应的端口映射，查看端口清单」，点击「查看端口清单」展示清单，点「我知道了」关闭。
- 内网端口映射说明：「尽量不使用 80/443 端口，避免与 http/https 服务冲突或被扫描攻击。」
- 互联网端口映射说明：「80/443 端口若要使用，需要完成网络备案。」

| 端口 | 协议 | 用途 |
|-----|-----|-----|
| 443 | tcp | 平台页面 |
| 1883 | tcp | 无人机通讯接口 |
| 9000 | tcp | 素材管理 |
| 21935 | tcp | 直播数据推流（与第 3 步默认值 11935 不一致，见附录C） |
| 18000 | rtc | 直播数据拉流，互联网模式下映射端口需与内部端口一致 |
| 11554 | rtsp | 直播数据拉流（单兵设备 AI 直播） |
| 8000 | tcp | 建图服务端口 |

**SSL 证书**

- 点击【+】选择文件后立即上传，显示进度百分比，完成后显示文件名和「上传成功」。
- 未上传时提示「若是不上传则会采用默认证书」。
- 点击【X】移除，恢复上传前状态。

**下一步**

- 校验所有输入框，未通过的字段在下方提示错误原因，整体提示「请检查标红字段」。
- 必填为空：「此项为必填项」。
- IP 类格式错误：「格式不正确，示例：192.168.1.100」。
- 访问地址格式错误：「访问地址格式不正确，示例：ops.example.com 或 192.168.1.100」。
- 全部通过后暂存所有字段，进入第 2 步。本步没有「上一步」。

**业务规则**

- 首次进入五个网络字段为空；本流程中点过「下一步」再回来，自动填入暂存值。
- 配置模式下从首页「获取最新ip」进入：IP 自动填入新值并提示用户确认，提示「已获取最新IP：{IP}，请确认后点「下一步」，并在第六步重启服务后生效」。

- 首页 IP 变更提醒依赖本步保存的 IP。

#### 3.5.3.2 设备激活配置（第 2 步）

##### （一）功能需求概述

通过「下载激活文件 → 商务或客服生成授权文件 → 上传授权文件」完成设备授权，授权决定设备授权时间和可接入设备数量。

##### （二）功能设计

**下载激活文件**

- 激活文件包含设备 ID（云盒唯一标识）及设备型号、序列号、MAC 地址、硬件指纹、系统版本、软件版本、生成时间。同一台设备每次下载的设备 ID 相同。
- 提示：「提示：下载云盒的唯一标识，给到商务或官方客服，获取授权文件」。
- 下载成功提示「激活文件已下载，请发给商务或官方客服获取授权文件」。

**上传授权文件**

- 点击选择或拖入，拖入多个只取第一个。选择后自动上传并验证，验证中显示「正在验证 {文件名} …」，期间不可重复选择。
- 通过：提示「授权文件验证通过」，切换为展示激活信息，【下一步】可点。
- 不通过：提示「该文件不正确」，上传区下方显示「该文件不正确，请重新选择授权文件」，可重新选择。
- 验证通过前【下一步】不可点击。

**激活信息（只读）**

| 字段 | 说明 | 示例 |
|-----|-----|-----|
| 云盒授权开始时间 | 日期 | 2025-05-19 |
| 云盒授权结束时间 | 日期或「永久授权」 | 永久授权 |
| 云盒授权设备数量 | licenseKey 对应的授权设备数量 | 4 |
| licenseKey | 只显示首尾 4 位，中间以 **** 打码 | SL5X-****-****-8636 |

许可 ID 后台保存、页面不展示；激活方式默认文件激活，页面不展示。

**业务规则**

- 配置模式下本步只展示激活信息，不提供重新上传（待确认：授权到期或扩容时的更换方式）。

**边界与异常**

- **已上传过授权文件**：再次进入本步时直接展示激活信息，【下一步】可点。
- **授权已到期**：处理方式（待确认）。
- **验证进行中**：不可重复选择文件，不可点击【下一步】。

- 授权文件由第三方授权系统生成，激活文件格式以研发与授权系统约定为准（待确认）。
- 验证通过是进入第 3 步的前提；授权设备数量体现在「项目信息」的设备授权额度中。

#### 3.5.3.3 基础服务配置（第 3 步）

##### （一）功能需求概述

配置平台运行依赖的四项基础服务：存储服务、通信服务、视频服务、时序服务。每项服务可选「内置配置」或「自定义」，默认内置配置，满足开箱即用与对接外部服务两类场景。

##### （二）功能设计

**配置方式**

- 四项服务各自单选「内置配置 / 自定义」，默认「内置配置」。
- 内置配置：展示系统默认值，只读，不做校验，可打开查看默认值。
- 自定义：字段可编辑，所有展示字段均为必填，点击「暂存并下一步」时统一校验，为空提示「请填写{字段名}」。
- 端口取值范围 1–65535；不做端口重复校验，但需验证端口连通。

**存储服务**

存储类型：内置配置固定为 minio；自定义可选 minio 或 OSS。

minio 展示字段：

| 字段名称 | 类型 | 长度限制 | 必填 | 默认值 | 说明 |
|---------|------|---------|------|-------|------|
| 服务器账号 | 文本输入 | 3–20 位 | 是 | 系统默认 | 字母、数字、下划线、中划线 |
| 服务器密码 | 密码输入 | 8–40 位 | 是 | 系统默认 | 不允许空格，默认密文 |
| 素材管理端口 | 数字输入 | 1–65535 | 是 | 9000 | 机场图片、视频素材的访问端口 |

minio 不展示、由系统固定的配置项：

| 配置项 | 取值 | 作用 |
|-------|-----|-----|
| 文件过期时间 | 36000 | 素材访问链接有效时长 |
| 存储桶 | dock | 素材存放位置 |
| 区域 | cn-shanghai | 存储区域标识 |
| EndPoint | 第 1 步访问地址 + 素材管理端口 | 素材访问地址 |
| CDN、角色ARN | 空 | 内置存储不使用 |

OSS 展示字段：

| 字段名称 | 类型 | 长度限制 | 必填 | 默认值 | 说明 |

#### 3.5.3.5 可选服务配置（第 5 步）

##### （一）功能需求概述

通过云端资源授权码开通靓马云端服务额度，并为 AI识别、二维建图、三维建模、AI比对四类可选服务选择部署方式。本步可不填写授权码、不启用任何服务，直接进入第 6 步。

##### （二）功能设计

**云端资源授权码**

| 字段名称 | 类型 | 长度限制 | 必填 | 默认值 | 说明 |
|---------|------|---------|------|-------|------|
| 云端资源授权码 | 文本输入 | 最长 32 位 | 否 | 空 | 开通靓马云端服务（AI识别、二维建图、三维建模、AI比对）的额度凭证；在翼飞平台的「云端资源授权码」中生成和获取；需联网验证 |

**验证授权码**

- 输入框为空时【验证授权码】不可点击；输入内容后可点击。
- 点击后先判断网络：无网时不发起验证，提示「您当前是无网环境，无法进行云端资源授权码验证」。
- 联网时由翼飞平台校验授权码，返回三项状态：是否存在、是否有效（未被禁用）、是否已被其他设备占用。
- 验证成功（存在、有效且未被占用）：授权码不可再编辑，【验证授权码】消失，出现【替换授权码】；展示授权码额度及提示「提示：若是需要增加额度，可联系商务或者官方客服增加。」；按额度自动启用对应模块。
- 验证失败（不存在、已禁用、已被占用任一情况）：统一提示「您的云端资源授权码不正确」，不区分、不展示具体原因。

**替换授权码**

点击后清空授权码并恢复可编辑，清空额度信息，已选择「靓马云端服务」的模块取消该部署方式，重新出现【验证授权码】，需重新验证。

**授权码额度**

| 额度项 | 单位 | 说明 |
|-------|-----|-----|
| 识别并发数 | 路 | AI识别同时处理的视频路数 |
| 算法数量 | 个 | 可使用的识别算法数量，点击可查看算法详情列表 |
| 二维建图额度 | 平方公里 | 云端二维建图可用面积 |
| 三维建模额度 | 平方公里 | 云端三维建模可用面积 |
| AI比对额度 | 次 | 云端 AI 比对可用次数 |

| 条件 | 联动结果 |

| 三维建模额度大于 0 | 三维建模自动启用，选择「靓马云端服务」 |
| AI比对额度大于 0 | AI比对自动启用，选择「靓马云端服务」 |
| 额度小于等于 0 | 不自动启用、不自动选择，但「靓马云端服务」仍可手动选择 |

| 步骤名称 | 系统初始化 | 重启服务 |
| 操作按钮 | 【保存并开始系统初始化】 | 【保存并重启服务】 |
| 提示文字 | 含「系统初始化」 | 「系统初始化」替换为「重启服务」 |
| 执行过程、进度、服务进展列表、日志下载、完成后的信息 | 一致 | 一致 |

**开始执行**

- 点击【上一步】返回第 5 步，已暂存内容保留。
- 点击【保存并开始系统初始化】：正式保存第 1–5 步配置，并同时启动本次涉及的全部服务；开始后不能返回上一步，转为进度展示。

**总进度**

- 执行中提示「系统初始化执行耗时：X秒，请您耐心等待」，耗时实时累加。
- 进度 = 已启动成功服务数 / 服务总数，以百分比展示。
- 全部成功后提示「系统初始化完成，总耗时：X秒」（配置模式为「重启服务完成，总耗时：X秒」）。

**服务进展列表**

- 列出本次需要启动的全部服务：基础服务必须启动；可选服务只列出第 5 步已启用的模块。
- 同时展示「启动服务：已成功数/总数」。
- 各服务同时启动，完成先后不固定。

| 字段名称 | 说明 |
|---------|-----|
| 序号 | 从 1 开始 |
| 服务名 | 服务名称；具体服务清单以研发实际部署为准（待确认） |
| 更新进度 | 服务当前状态，见下表 |
| 执行耗时 | 单位秒；等待中的服务显示「-」 |
| 重启次数 | 检测不通过后自动重启的次数，初始为 0 |
| 服务日志 | 服务开始启动后可点击【查看】下载日志；等待中的服务显示「-」 |

**服务状态**

| 状态 | 说明 |
|-----|-----|
| 等待中 | 已下发启动，尚未开始执行 |
| 启动中 | 服务正在启动 |
| 检测中 | 启动完成，正在检测服务是否可用 |
| 重试中 | 检测不通过，自动重启，重启次数加 1 |
| 启动成功 | 检测通过 |

状态流转：等待中 → 启动中 → 检测中 → 启动成功；检测不通过时 → 重试中 → 启动中，循环至检测通过。

**服务日志**

- 点击【查看】直接下载该服务的日志文件，文件名为「{服务名}_服务日志_{时间}.log」，下载后提示「已下载{服务名}日志」。
- 日志内容：服务名称、开始时间、结束时间（未结束时为「未结束」）、执行耗时、重启次数、执行结果（成功 / 未完成），以及启动、检测、重启各步骤的执行明细；执行不成功时写明具体问题。
- 用途：初始化长时间未完成或停在某个服务时，下载日志交给研发人员排查。

**初始化完成**

全部服务启动成功后，不再展示进度和服务进展列表，转为展示系统信息：

| 信息项 | 内容 | 操作 |
|-------|-----|-----|
| 项目名称 | 第 4 步填写的项目名称 | - |
| 应用平台 | 应用平台登录网址 | 可点击跳转、可复制 |
| 管理后台 | 管理后台登录网址 | 可点击跳转、可复制 |
| 运维中心地址 | 运维中心登录网址 | 可点击跳转、可复制 |
| 设备上云 | MQTT服务地址、MQTT用户名、MQTT密码、组织码、设备绑定码，只读展示 | 一键复制全部内容 |

- 单项复制成功提示「已复制：{内容}」；设备上云一键复制按每项一行「名称：值」复制，提示「已复制设备上云信息」；复制失败提示「复制失败，请手动复制」。
- 点击【关闭】进入首页，设备变为已激活状态，首页「激活」入口变为「配置」。

**业务规则**

- 第 1–5 步的配置在点击本步开始按钮后才正式保存。
- 执行中点击返回：不能离开，激活模式提示「系统初始化进行中，请稍候」，配置模式提示「重启服务进行中，请稍候」。
- 未开始执行时点击返回：按向导返回确认规则处理（见 3.5.3.0）。
- 执行完成后点击返回：直接进入首页。

**边界与异常**

- **服务反复检测不通过**：原型未限制自动重启次数；是否设置上限、达到上限后如何提示，待确认。
- **执行中关闭浏览器或断电**：再次进入时的进度恢复方式待确认。
- **登录网址与设备上云信息的生成规则**：由第 1 步访问地址、第 3 步通信服务配置及翼飞平台生成，具体规则待确认。

##### （三）业务逻辑关联

- 项目名称来自第 4 步；设备上云信息与第 3 步通信服务配置相关。
- 完成后的已激活状态决定首页入口矩阵（见 3.5.2）；已启动的服务纳入「服务监测」。

### 3.5.4 升级

#### （一）功能需求概述

分别对翼飞平台和运维中心进行版本升级，支持在线更新和本地更新两种方式。展示可更新的版本、更新进度、各服务的更新结果，并记录每次更新的日志。某个服务更新失败时系统整体回滚到更新前版本。

#### （二）功能设计

**更新对象**

| 更新对象 | 版本号规则 | 说明 |
|---------|-----------|------|
| 翼飞平台更新 | 以 B 开头，如 B1.1.0 | 默认进入 |
| 运维中心更新 | 以 V 开头，如 V1.2.0 | - |

- 两个更新对象相互独立：更新方式、版本列表、下载、更新进度、更新日志互不影响，规则相同。
- 某一对象正在更新时不能切换，提示「{平台名称}正在更新中，请稍后再切换」；正在下载时提示「升级安装包下载中，请稍后再切换」。
- 重新进入升级时，自动进入正在更新的对象。
- 从首页点击「升级」进入，默认展示版本列表。

**更新方式**

| 更新方式 | 操作步骤（鼠标悬停说明文字） | 说明 |
|---------|--------------------------|------|
| 在线更新（默认） | 1、下载升级安装包；2、执行更新操作 | 联网时自动获取可更新版本；更新前先下载升级安装包 |
| 本地更新 | 1、记录当前版本号发送给商务人员；2、下载商务人员给的升级安装包；3、导入升级安装包；4、页面点击更新 | 导入升级安装包后再更新，无需下载 |

- 两种方式的操作说明末尾均附「注：升级过程受更新服务版本的差异性以及下载（导入）速度不一样，升级时间有所差异，请耐心等待。」
- 更新进行中不可切换更新方式，提示「更新进行中，不可切换更新方式」。
- 在线更新时设备无网，提示「网络异常，无法获取在线版本」，引导切换为本地更新。

**版本列表**

| 字段名称 | 说明 |
|---------|------|
| 版本号 | 按版本号从高到低排序 |
| 版本描述 | 该版本的更新内容 |
| 升级状态 | 见下表 |
| 操作 | 按状态提供【下载】【更新】【查看进度】【日志】【删除】 |

列表支持分页，默认每页 10 条。本地更新且未导入任何安装包时，提示「暂无版本，请点击「导入版本服务」导入升级安装包」。

| 升级状态 | 条件 | 可用操作 |
|---------|-----|---------|
| 已更新 | 低于当前版本 | 不支持回溯更新 |
| 当前版本 | 等于当前版本 | 不支持更新 |
| 待更新（未下载） | 在线更新且未下载安装包 | 【下载】 |
| 待更新（已下载 / 已导入） | 已下载或本地已导入 | 【更新】 |
| 待更新（更新失败） | 上次更新失败 | 【更新】继续更新、【日志】查看失败日志 |
| 更新中 | 正在更新该版本 | 【查看进度】，不支持再次更新 |

本地更新方式下，非更新中的版本均可【删除】，确认后删除该安装包，需重新导入。

**下载（在线更新）**

1. 先判断网络：无网时提示「网络不可用，无法在线获取升级安装包，请使用本地更新」。
2. 联网时确认「是否下载远程镜像？预计大小 xxGB」，下载内容为当前版本到该版本的增量镜像和数据处理脚本（通用版本）。
3. 下载期间该版本显示「下载中」，其他下载、更新操作不可用；下载完成后，当前版本与该版本之间的中间版本同时变为可更新。

**导入版本服务（本地更新）**

仅本地更新方式提供。更新进行中不可导入，提示「更新进行中，暂不可导入」。

| 项目 | 规则 |
|-----|-----|
| 文件格式 | .zip / .tar / .tar.gz |
| 导入过程 | 导入文件 → 判断内存 → 解压 → 校验文件 → 读取包内版本 → 校验服务是否完整；过程中可【取消导入】，提示「已取消导入」 |
| 内存不足 | 提示「您的内存不足，请前往处理」 |
| 文件损坏 | 提示「您导入的文件已损坏」 |
| 安装包不完整 | 提示「您导入的升级安装包不完整，请联系客服人员解决」，列表不展示该版本 |
| 版本不高于当前版本 | 提示无需导入 |
| 导入成功 | 列表展示该版本及其与当前版本之间的版本，状态为待更新，提示「{版本号列表} 导入成功」 |
| 重复导入 | 更新对应版本的服务内容 |

失败后可【重新导入】。

**更新**

- 点击【更新】确认「确定将系统从 {当前版本} 更新到 {目标版本} 吗？更新过程中服务会依次重启，业务可能短暂不可用，请勿关闭电源或刷新页面。」
- 同一时间只能更新一个版本；确认后进入更新服务列表。

**更新进度**

| 阶段 | 提示内容 |
|-----|---------|
| 下载中（仅在线更新） | 正在下载目标版本升级安装包，请耐心等待 |
| 更新中 | 「系统更新升级耗时：xx分xx秒，请您耐心等待。」并说明当前正在更新第几个服务 |
| 更新成功 | 「更新耗时：xx分xx秒，更新成功！系统当前版本为 {目标版本}」 |
| 更新失败 | 「更新失败：「{服务名称}」更新异常，耗时 xx分xx秒，系统已回滚到 {原版本}。可在版本列表中继续更新或查看日志」 |

- 总进度以百分比展示。
- 更新中可离开本页，首页展示「{平台名称}系统正在更新中」；返回后继续展示进度。
- 更新结束后点击【返回版本列表】，不再展示本次进度。

**更新服务列表**

| 字段名称 | 说明 |
|---------|------|
| 序号 | 从 1 开始 |
| 服务名称 | 本次需要更新的服务 |
| 当前版本 | 更新前版本；成功后为新版本 |
| 更新后版本 | 本次目标版本 |
| 更新进度 | 等待中 / 百分比 / 成功 / 失败 / 已回滚 / 未更新 |

- 同时展示「更新服务：已完成数/总数」。
- 各服务按顺序逐个更新；某个服务失败时，已更新的服务回滚，后续服务不再更新。

**结束进程**

更新长时间停在进行中时，可点击【结束进程】，确认「确定结束本次更新进程吗？结束后已更新的服务回滚到 {原版本}，版本状态仍为「待更新」，可继续更新。」确认后系统回滚，提示「已结束本次更新进程」。

**更新日志**

| 查询条件 | 说明 |
|---------|------|
| 更新时间 | 起止日期范围 |
| 更新版本 | 按更新后版本筛选，默认全部 |

【查询】按条件筛选，【重置】清空条件。

| 字段名称 | 说明 |
|---------|------|
| 序号 | 从 1 开始 |
| 更新时间 | 年-月-日 时:分:秒，按时间倒序 |
| 更新前版本 / 更新后版本 | 本次更新的起止版本 |
| 结果 | 成功 / 失败 |
| 操作 | 【详情】：展示更新方式（在线 / 本地），以及每个服务的名称、更新后版本（如 V1.21.4）、更新结果 |

列表支持分页，默认每页 10 条；无记录时提示「暂无更新记录」。

**业务规则**

- 更新成功后，目标版本变为当前版本，之前的版本均变为已更新。
- 更新失败或结束进程后，当前版本不变，目标版本仍为待更新。
- 每次更新（成功、失败、结束进程）均记录一条更新日志。

**边界与异常**

- **导入失败提示文案**：原型存在两套文案（如「您的内存不足，请前往处理」与「导入失败：设备内存不足，请清理磁盘空间后重新导入」），以前者为准（待确认）。
- **下载预计大小**：按实际增量计算，具体值由研发提供。
- **失败日志内容**：由研发提供（待确认）。
- **服务清单**：翼飞平台、运维中心各自需要更新的服务以研发实际部署为准（待确认）。
- **更新中断电或重启**：恢复方式待确认。

#### （三）业务逻辑关联

- 首页展示更新中状态，并控制其他入口的可用性（见 3.5.2）。
- 运维中心更新涉及第 5 步可选服务（AI识别、二维建图、三维建模、AI比对）。
- 更新期间与备份、复原、重置的互斥关系见 3.5.2 首页入口矩阵。

### 3.5.5 备份

#### （一）功能需求概述

备份运维中心管理的业务数据，支持自动备份和手动备份两种方式。可设置自动备份周期、备份内容和备份文件存放方式（本地 / 本地+云端），可对现有备份数据执行删除、还原、下载，并记录每次备份（成功和失败都记录）。

#### （二）功能设计

**页面信息**

- 分为「自动备份」「手动备份」两类。
- 展示当前系统版本和本地剩余空间；点击【刷新】重新读取剩余空间，提示「剩余空间已刷新」。

**自动备份配置**

| 字段名称 | 类型 | 取值范围 | 必填 | 默认值 | 说明 |
|---------|------|---------|------|-------|------|
| 自动备份 | 开关 | 开启 / 关闭 | 是 | 开启 | 关闭后下方配置不可编辑，系统不再自动备份。切换后提示「已开启自动备份」/「已关闭自动备份」 |
| 自动备份时间 | 天数 + 时间点 | 每 1–30 日，时间点精确到分钟 | 是 | 每 1 日 02:00（待确认） | 每 N 日在指定时间点执行一次 |
| 下次备份时间 | 只读 | - | - | 自动计算 | 上次自动备份时间 + N 日的指定时间点；无自动备份记录时从当前时间起算 |
| 备份内容 | 多选 | 基础数据、飞行数据、成果数据 | 是 | 全选（待确认） | 基础数据影响系统运行，必选且不可取消；飞行数据、成果数据可选 |
| 备份文件方式 | 单选 | 本地备份 / 本地备份+云端备份 | 是 | 本地备份（待确认） | 见下表 |

| 备份文件方式 | 说明 |
|------------|------|
| 本地备份 | 备份文件只保存在云盒本地磁盘，占用本地剩余空间 |
| 本地备份+云端备份 | 本地保存一份，同时上传一份到云端对象存储，需填写云端存储参数 |

**云端存储参数（选择「本地备份+云端备份」时填写）**

| 字段名称 | 必填 | 说明 |
|---------|------|------|
| 文件过期时间 | 是 | 云端备份文件的保存期限，单位待确认 |
| 存储桶名称 | 是 | 云端对象存储的存储桶 |
| EndPoint地址 | 是 | 云端对象存储访问地址 |
| CDN地址 | 否 | 加速访问地址 |
| AccessKeySecret | 是 | 访问密钥 |
| AccessKeyId | 是 | 访问密钥 ID |

**保存**

- 校验自动备份天数在 1–30 之间；选择「本地备份+云端备份」时校验带 * 的云端存储参数均已填写，未通过时提示对应字段，不保存。
- 校验通过后保存配置，并按新配置重新计算下次备份时间。

**手动备份**

| 字段名称 | 说明 |
|---------|------|
| 序号 | 从 1 开始 |
| 导出数据 | 全量数据、基础数据、飞行数据、成果数据，共 4 行；全量数据 = 基础 + 飞行 + 成果数据 |
| 大小 | 最近一次成功备份的大小（GB）；未备份显示「—」 |
| 状态 | 未备份 / 备份中 / 已备份 |
| 备份时间 | 最近一次成功备份时间；未备份显示「—」 |
| 操作 | 【备份】【下载】；已备份时可下载最近一次备份 |

- 点击【全量备份】或某行【备份】开始备份，展示备份进度（百分比）及提示「正在备份「{备份内容}」，请勿关闭页面…」。
- 备份中可点击【后台运行】，备份在后台继续执行。
- 同一时间只允许一个备份任务；还原进行中不能发起备份，提示「有备份或还原任务进行中，请稍后」（待确认：与首页「导入复原中，请稍后再试」统一）。

**备份结果**

| 结果 | 条件 | 提示 | 处理 |
|-----|-----|-----|-----|
| 成功 | 备份完成 | 「「{备份内容}」备份完成，大小 X GB」 | 扣减剩余空间，生成备份数据 |
| 云端上传失败 | 本地备份完成，上传云端失败 | 「「{备份内容}」已备份到本地，大小 X GB。上传云端失败：网络异常，请检查网络和云端存储参数。」 | 记为成功，数据存储为「本地（云端上传失败）」 |
| 失败：剩余空间不足 | 备份前判断剩余空间不足 | 「失败原因：剩余空间不足，请清理磁盘或删除旧的备份数据后重试。」 | 不生成备份数据；可【重新备份】 |
| 失败：任务中断 | 其他操作导致任务中断 | 「失败原因：其他操作导致任务中断，请勿在备份过程中进行升级、还原、重置等操作。」 | 不生成备份数据；可【重新备份】 |

**备份数据**

列出现存的成功备份，按备份时间倒序。

| 字段名称 | 说明 |
|---------|------|
| 序号 | 从 1 开始 |
| 备份数据 | 备份文件名称，命名规则由研发提供（待确认） |
| 备份方式 | 自动备份 / 手动备份 |
| 备份内容 | 全量数据或具体数据类别 |
| 备份大小 | 单位 GB |
| 备份时间 | 年-月-日 时:分:秒 |
| 操作 | 【删除】【还原数据】【下载】 |

- **删除**：确认「确定删除备份数据「{名称}」吗？删除后不可恢复。」后删除，数据状态记为「手动删除」，释放空间，提示「已删除」；还原进行中不可删除，提示「还原进行中，暂不能删除」。
- **还原数据**：展示备份数据、系统版本、项目、备份时间、备份内容，并提示「还原会覆盖系统中对应的数据，还原期间请勿进行升级、备份、重置等操作。是否继续？」；确认后展示恢复进度，完成后提示「「{备份内容}」已恢复到系统中」。有备份或还原任务进行中时提示「有备份或还原任务进行中，请稍后」。
- **下载**：下载 zip 包到本地，提示「开始下载：{名称}」。
- 无数据时提示「暂无备份数据」。

**备份记录**

点击【备份记录】查看每次备份（含失败），按时间倒序；无记录时提示「暂无备份记录」。

| 字段名称 | 说明 |
|---------|------|
| 序号 | 从 1 开始 |
| 备份数据 | 备份文件名称 |
| 备份方式 | 自动备份 / 手动备份 |
| 备份类型 | 全量备份 / 部分备份 |
| 数据存储 | 本地 / 本地+云端 / 本地（云端上传失败） |
| 备份大小 | 单位 GB；失败显示「—」 |
| 备份时间 | 年-月-日 时:分:秒 |
| 备份耗时 | 时:分:秒 |
| 备份成功 | 成功 / 失败：{原因}（剩余空间不足、网络异常、其他操作导致任务中断） |
| 数据状态 | 存在 / 系统删除 / 手动删除 |

**业务规则**

- 手动全量备份最多保留 5 份，超出时系统自动删除最早的一份，数据状态记为「系统删除」并释放空间。
- 自动备份数据的保留份数：原型文字为「仅保留最近 5 份全量备份数据 + 自动备份数据」，自动备份是否也限 5 份待确认。
- 备份与升级、复原、重置互斥，见 3.5.2 首页入口矩阵。

**边界与异常**

- **自动备份执行时设备关机**：开机后是否补备份待确认。
- **云端上传失败后是否重传**：原型仅提示，未提供重传操作（待确认）。
- **文件过期时间单位与范围**：待确认。

- 备份期间首页复原、升级、重置入口的可用性见 3.5.2。
- 云端存储参数与第 3 步基础服务配置中的 OSS 参数是否复用待确认。

### 3.5.6 复原

#### （一）功能需求概述

把系统数据恢复到某份备份数据的状态，有「一键还原」和「导入还原」两种方式。一键还原从本机最近的备份数据中选一份直接复原；导入还原上传外部备份文件，按基础数据、飞行数据、成果数据分步导入。任何一步失败，系统数据都不改动。

#### （二）功能设计

**页面信息**

- 分为「一键还原」「导入还原」两类，默认进入一键还原；复原进行中不能切换。
- 页面说明：「复原会占用服务，系统数据会按照您选择的备份数据进行还原，建议您在此期间不再使用翼飞平台。复原时间会根据备份数据大小不同而不同，请您耐心等待」。
- 导入还原展示当前系统版本和本地剩余空间，可刷新；剩余空间与备份页面一致。

**一键还原：复原数据**

只展示最新的 5 份成功备份数据，按备份时间倒序，单选，默认不选中；点选择项或整行均可选中。

| 字段名称 | 说明 |
|---------|------|
| 选择 | 单选 |
| 序号 | 从 1 开始 |
| 备份名称 | 备份数据名称 |
| 版本号 | 备份时的系统版本 |
| 备份内容 | 全量数据或具体数据类别 |
| 备份方式 | 自动备份 / 手动备份 |
| 数据大小 | 单位 GB |
| 备份时间 | 年-月-日 时:分:秒 |

无数据时提示「暂无可复原的数据，请先到「备份」页面备份」，点击「备份」进入备份页面。

**一键还原：开始复原**

| 条件 | 【开始复原】 |
|-----|------------|
| 有备份任务进行中（自动或手动） | 不可点击，并提示「当前有备份任务正在进行中，「开始复原」暂不可用，请等待备份完成后再操作。」；备份完成后自动恢复 |
| 无备份任务、未选择数据 | 不可点击 |
| 无备份任务、已选择数据 | 可点击 |
| 无可复原的数据 | 不可点击 |
| 复原进行中 | 不可再次点击 |

- 自动备份开关是否开启不影响复原。
- 点击时所选数据已不存在，提示「该备份数据已不存在，请重新选择」，并刷新列表。
- 系统尚无项目数据（未激活）时不能复原，提示「数据上传失败。原因：系统项目数据不存在，不支持上传。请先完成激活，配置项目信息。」
- 开始后展示复原进度（百分比及当前执行步骤），提示「导入复原中，复原会占用服务，建议您在此期间不再使用翼飞平台」，并展示复原数据名称。复原过程共 7 个步骤，步骤名称由研发提供（待确认）。

**取消复原**

复原中可点击【取消复原】，确认「确定取消复原吗？取消后系统数据保持复原前的状态。」；选择【继续复原】回到进度，选择【确定取消】后提示「已取消复原」。

**一键还原结果**

| 结果 | 提示 |
|-----|-----|
| 成功 | 「导入成功，系统已按「{备份名称}」复原」 |
| 空间不足 | 「您的空间不足，请前往处理」，并说明剩余空间与该备份所需空间，引导到「备份」页面删除不需要的备份数据 |
| 上传失败 | 「数据上传失败。原因：上传过程中网络中断。系统数据未改动。」 |
| 文件损坏 / 版本不兼容 / 模块不一致 / 执行失败 | 「数据导入执行失败。原因：{文件损坏 / 导入数据版本不兼容 / 导入数据对应模块不一致 / 执行复原时出错}。系统数据未改动。」 |

**导入还原：分步导入**

| 步骤 | 是否必须 | 说明 |
|-----|---------|-----|
| 第 1 步 基础数据 | 必须 | 不导入系统无法正常展示数据；导入成功后才能进入下一步，否则提示「请先导入基础数据」 |
| 第 2 步 飞行数据 | 可选 | 可不上传直接下一步；不导入时飞行业务没有历史数据 |
| 第 3 步 成果数据 | 可选 | 规则同第 2 步；不导入时成果业务没有历史数据 |
| 第 4 步 执行成功 | - | 展示已导入、未导入的数据 |

每一步的操作：

1. **上传备份数据**：只支持 .zip，其他格式提示「只支持 .zip 格式的备份数据」。上传成功后展示文件名、导入版本、项目信息、备份时间、上传时间，提示「{数据类别}上传成功」。导入前可移除重新上传，导入后不能移除。
2. **导入系统并执行**：上传后才可点击；有备份任务进行中时提示「备份任务进行中，请稍后再导入」。执行中展示进度及提示「正在导入「{数据类别}」并执行，复原会占用服务，建议您在此期间不再使用翼飞平台…」。成功后提示「{数据类别}导入成功」。
3. **下一步**：飞行 / 成果数据已上传但未导入时，确认「已上传的「{数据类别}」还没有导入系统，跳过后不会导入，对应业务没有历史数据。确定跳过吗？」

上传与导入失败：

| 情况 | 提示 |
|-----|-----|
| 文件损坏 | 「数据上传失败。原因：「{文件名}」文件损坏，无法解析，请重新上传。」 |
| 版本不一致 | 「这份备份数据对应的系统版本是 {备份版本}，当前系统版本是 {当前版本}，不能导入。请先把系统升级到相同版本，或换一份同版本的备份数据。」 |
| 备份类型不符 | 「这份文件不是「{数据类别}」备份数据，请重新上传」 |
| 执行失败 | 「数据导入执行失败。原因：「{数据类别}」数据校验未通过，{系统数据未改动 / 已导入的数据不受影响}。请重新上传或换一份备份数据。」第 1 步为前者，第 2、3 步为后者 |

第 4 步提示「执行成功，数据已导入，可以进入系统使用」，列出已导入、未导入的数据（未导入的对应业务没有历史数据）。点击【进入系统】回到首页，点击【重新导入】从第 1 步重新开始。

**业务规则**

- 复原期间不能离开本页，点击返回提示「还原进行中，请勿离开页面」。
- 复原与备份互斥：备份进行中不能复原；复原进行中不能备份、删除备份数据。与升级、重置的互斥见 3.5.2 首页入口矩阵。
- 复原期间首页提示「导入复原中，请稍后再试」。
- 复原只覆盖所选备份内容对应的数据。

**边界与异常**

- **一键还原的版本校验**：备份版本与当前版本不一致时是否允许一键还原，原型仅有「版本不兼容」结果，规则待确认。
- **复原中断电或重启**：恢复方式待确认。
- **导入还原是否可取消**：原型未提供取消操作（待确认）。
- **空间不足的判断时机**：原型在复原执行后提示，是否应在开始前判断待确认。

#### （三）业务逻辑关联

- 一键还原的数据来源为 3.5.5 备份的「备份数据」；导入还原的文件来自备份数据【下载】得到的 zip 包。
- 依赖第 4 步项目信息：未激活的系统不能复原。
- 首页入口可用性见 3.5.2。

### 3.5.7 服务监测

#### （一）功能需求概述

实时展示设备的 CPU、内存、存储空间、网络、GPU 资源使用情况和各服务的运行状态，可下载单个服务的运行日志，可查看基础服务的配置详情，并可一键重启所有服务。本功能不受激活状态限制，未激活时也可进入。

#### （二）功能设计

**资源概况**

进入页面后展示以下资源信息，每 3 秒自动刷新一次。

| 资源项 | 展示内容 | 说明 |
|-------|---------|------|
| CPU | 占用比例（%） | - |
| 内存 | 内存上限、已消耗（GB） | - |
| 存储空间 | 数据磁盘、建图磁盘，格式为「已用 / 总量」（GB） | 超脑版展示数据磁盘和建图磁盘；标准版一体机没有建图磁盘，只展示数据磁盘 |
| 网络 | 上传速度、下载速度 | 单位随数值自动换算（待确认换算规则） |
| GPU | 显存使用（已用 / 总量，MiB）、温度（℃） | 设备有 GPU 时展示；没有 GPU 时不展示该项。标准版一体机没有 GPU |

**服务列表**

| 字段名称 | 说明 |
|---------|------|
| 序号 | 从 1 开始 |
| 业务模块 | 基础服务 / 业务平台 / 可选服务 |
| 服务名称 | 服务名称 |
| 版本号 | 服务当前版本 |
| 业务端口号 | 服务对外端口 |
| 服务状态 | 正常 / 异常；异常时同时展示异常原因，如「网络服务异常」「服务进程异常，端口无响应」 |
| 服务日志 | 点击【查看】下载该服务的运行日志 |

- 原型示例服务：基础服务（数据库、缓存、消息队列、存储、视频、网关）、业务平台服务、可选服务（AI识别、二维建图、三维建模、AI比对）。具体服务清单和端口以研发实际部署为准（待确认）。
- 可选服务只列出第 5 步已启用的模块（待确认：原型未明确未启用模块是否列出）。
- 运行日志文件名为「{服务名}_服务日志_{时间}.log」，内容包括服务名称、版本号、业务端口号、服务状态及异常原因、运行记录；下载后提示「已下载{服务名}日志」。
- 异常的服务可通过「所有服务重启」恢复。

**基础服务详情**

- 点击【基础服务详情】，按「存储服务、通信服务、视频服务、时序服务」分组只读展示各基础服务的地址、端口、账号、密钥等配置信息。
- 各分组字段与第 3 步基础服务配置一致（见 3.5.3.3）。
- 原型要求密码、密钥明文展示，便于出现问题时研发人员快速排查（待确认：明文展示存在泄露风险，是否改为默认不显示明文、点击后查看）。
- 点击【全部复制】，按「分组 + 字段：值」的纯文本格式复制全部内容，提示「已复制全部内容」，详情不关闭；复制失败提示「复制失败，请手动选中复制」。
- 点击【关闭】关闭详情。

**所有服务重启**

1. 点击【所有服务重启】，确认「重启期间所有业务暂时不可用，是否确认重启所有服务？」，可取消或确定。
2. 确定后转为重启进度展示：总进度、服务进展列表、服务状态流转、执行耗时、重启次数、服务日志下载，规则与配置模式第 6 步「重启服务」一致（见 3.5.3.6）。
3. 执行中提示「重启服务执行耗时：X秒，请您耐心等待」，耗时实时累加；进度 = 已启动成功服务数 / 服务总数。
4. 全部服务启动成功后，提示「重启服务完成，总耗时 X 秒，所有服务已启动成功。」，不展示项目信息和登录网址；点击【确定】回到服务监测页面。

**业务规则**

- 服务监测不受激活状态限制。
- 重启进行中不能返回、不能离开页面，点击返回提示「重启服务进行中，请稍候」。
- 重启进行中不能再次发起重启。
- 重启完成后服务列表重新读取最新状态。

**边界与异常**

- **重启中某个服务反复检测不通过**：与第 6 步一致，自动重启次数上限待确认。
- **资源信息读取失败**：原型未说明展示方式（待确认）。
- **升级、备份、复原进行中发起重启**：互斥规则原型未说明（待确认）。
- **网络速度单位**：原型示例为「b」，单位与换算规则待确认。

#### （三）业务逻辑关联

- 服务清单与第 6 步启动的服务一致，可选服务来自第 5 步配置。
- 基础服务详情的数据来自第 3 步基础服务配置。
- 所有服务重启的执行过程复用第 6 步「重启服务」的规则。
- 首页「服务监测」入口不受激活状态限制（见 3.5.2）。

**项目基本信息**

|-------|-----|-----|
| 项目名称 | 激活 / 配置第 4 步填写的项目名称 | - |

**系统登录网址**

|-------|-----|-----|
| 应用平台 | 应用平台登录网址 | 可复制 |

**设备上云**

| 信息项 | 说明 |
|-------|-----|
| MQTT服务地址 | 设备接入的 MQTT 服务地址 |
| MQTT用户名 | MQTT 接入账号 |

### 3.5.9 重置

#### （一）功能需求概述

将设备回归出厂设置：清除所有业务数据、应用数据和配置，设备回到未激活状态，需重新激活后才能继续使用。建议重置前先备份数据。

#### （二）功能设计

**页面说明**

展示提示：「重置后所有业务数据、应用数据，回归出厂设置，若是要继续使用需要您重新激活，建议提前备份数据信息。重启预计10分钟，请耐心等待」。

**操作流程**

1. 点击【回归出厂设置】，确认「初始化将清除所有数据，请确认是否继续？」，可取消或确定。
2. 确定后先判断是否有其他任务进行中（见业务规则），有则提示原因，不执行重置。
3. 无冲突时进入数据初始化，提示「重置进行中，正在初始化数据，请勿关闭页面或断电」，并展示进度；此过程不可取消。
4. 初始化完成后提示「重置完成，3 秒后进入运维中心，请重新激活」，倒计时结束后进入首页，设备为未激活状态：只有「激活」与「服务监测」可用（见 3.5.2）。

**重置结果**

| 结果 | 提示 | 处理 |
|-----|-----|-----|
| 成功 | 「重置完成，3 秒后进入运维中心，请重新激活」 | 清除业务数据和配置，设备回到未激活状态 |
| 失败 | 「回归出厂设置失败。失败原因：数据初始化出错，系统数据未改动。请稍后重试，或联系运维人员。」 | 系统数据不改动，可重新发起重置 |

**清除范围**

- 所有业务数据、应用数据、激活向导第 1–6 步的配置、备份与复原记录、升级记录。
- 所有数值回归默认状态，包括恢复设备激活码和云联密钥。
- 备份数据文件是否一并清除，原型未明确（待确认）。

**业务规则**

- 升级、备份、复原进行中不能重置，提示原因，如「{平台名称}系统正在更新中，请稍后再重置」；备份、复原进行中的提示文案待确认。
- 重置进行中不能离开本页，点击返回提示「重置进行中，请勿离开页面」；关闭或刷新浏览器时给出离开确认。
- 重置进行中不能再次发起重置。
- 重置与升级、备份、复原互斥，见 3.5.2 首页入口矩阵。

**边界与异常**

- **重置中断电或重启**：恢复方式待确认。
- **重置是否需要二次身份验证**（如输入管理员密码）：原型未要求（待确认）。
- **运维中心登录账号密码是否一并恢复默认**：原型未说明（待确认）。

#### （三）业务逻辑关联

- 重置后设备回到未激活状态，首页入口按未激活状态展示（见 3.5.2），需重新走激活向导（见 3.5.3）。
- 重置前建议通过 3.5.5 备份导出数据，重新激活后可通过 3.5.6 复原恢复。

### 3.5.10 个人中心（修改密码 / 退出登录）

#### （一）功能需求概述

当前登录账号可修改自己的登录密码、维护手机号，并可退出登录。使用初始密码首次登录时，系统主动引导修改密码。

#### （二）功能设计

**账号菜单**

- 展示当前登录账号（如 admin），点击展开菜单，再次点击或点击其他区域收起。
- 菜单项：【修改密码】【退出登录】。
- 退出登录：清除登录状态，返回登录页。

**修改密码：进入方式**

| 方式 | 说明 |
|-----|-----|
| 主动修改 | 从账号菜单点击【修改密码】进入 |
| 首次登录引导 | 使用出厂初始密码登录成功后，系统自动进入修改密码 |

**修改密码：字段**

| 字段名称 | 类型 | 必填 | 规则 |
|---------|------|------|------|
| 账号名 | 只读 | - | 当前登录账号，不可修改 |
| 手机号 | 国家/地区 + 号码 | 否 | 不填不校验；填写后按所选国家/地区规则校验，见下表；默认中国 +86 |
| 旧密码 | 密码 | 是 | 与当前密码不一致时提示「旧密码错误」；默认密文，可切换明文 |
| 新密码 | 密码 | 是 | 8–16 位，必须同时包含大写和小写字母；不能与旧密码相同；输入时展示密码强度；默认密文，可切换明文 |
| 确认新密码 | 密码 | 是 | 必须与新密码一致，否则提示「两次输入的密码不一致」 |

**手机号校验规则**

| 国家/地区 | 区号 | 位数 | 开头数字 |
|----------|-----|-----|---------|
| 中国（默认） | +86 | 11 位 | 1，且不能是 10、11、12 |
| 中国香港 | +852 | 8 位 | 5、6、7、9 |
| 中国澳门 | +853 | 8 位 | 6 |
| 英国 | +44 | 10 位 | 7 |
| 葡萄牙 | +351 | 9 位 | 9 |
| 泰国 | +66 | 9 位 | 6、8、9 |
| 印尼 | +62 | 10–12 位 | 8 |
| 越南 | +84 | 9–10 位 | 3、5、7、8、9 |

其他国家/地区待有客户需求后补充。

**提交与结果**

- 点击【确定】时校验全部字段，未通过的字段分别给出错误提示，不提交。
- 修改成功提示「密码修改成功，请重新登录」，清除登录状态并返回登录页。
- 点击【取消】或关闭：不保存，回到原页面。

**业务规则**

- 密码强度的分级规则（弱 / 中 / 强）待确认。
- 新密码规则与第 4 步管理员密码规则一致（8–16 位，含大小写字母）。

**边界与异常**

- **首次登录不强制改密**：使用初始密码登录后自动打开修改密码窗口，用户可直接关闭，关闭后正常使用各功能；下次使用初始密码登录时仍会自动打开。（已确认，以首页标注为准，登录页「修改完成前不能进入其他功能」的描述作废。）
- **手机号用途**：原型未说明手机号用于找回密码还是通知（待确认）。
- **修改密码后其他已登录会话是否失效**：原型未说明（待确认）。

- 修改成功后回到 3.5.1 登录页，用新密码登录。
- 重置后登录密码是否恢复初始密码，见 3.5.9 边界与异常。

- **操作记录**：升级、备份、复原均保留执行记录与日志；登录、配置变更是否记录审计日志待确认。
