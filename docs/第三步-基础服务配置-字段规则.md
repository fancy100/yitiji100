# 激活第三步：基础服务配置 字段规则（已确认）

> 依据：B1.3.0 原型截图、字段说明表、黄色注释，以及评审确认结果。

## 一、通用规则

| 项 | 规则 |
|---|---|
| 配置选择 | 四个模块各有一个，单选「内置配置 / 自定义」，必填。默认「内置配置」（已确认） |
| 内置配置 | 模块默认展开，字段显示内置默认值，只读（置灰），不校验格式（已确认） |
| 自定义 | 字段可编辑，按下面的规则校验。失焦时校验，标红并在字段下方提示 |
| 端口类字段 | 必填，1–65535 的整数。**不做端口重复校验**（已确认） |
| 密码类字段 | 默认密文，点小眼睛切换明文 |
| 暂存并下一步 | ① 先做格式校验，有错误就停在当前页 ② 再依次验证存储、通信、视频、时序服务的连通性（含对应服务的端口是否正确） ③ 任一不通过：提示「xx服务链接不上，请检查修改xx服务相关配置。」，并框选对应模块 ④ 全部通过：数据存入暂存状态，进入第四步 |
| 暂存 | 点「重启服务」完成系统初始化后才真正保存。暂存后点「上一步」再回来，能看到修改过的内容；返回运维中心后再进来，显示系统正在运行的值 |
| 上一步 | 回到第二步，不校验 |

## 二、存储服务

提示：该配置用于机场获取的图片、视频数据存放，若是修改，需要重启服务，请谨慎修改。

| 字段 | 必填 | 默认值 | 限制 |
|---|---|---|---|
| 存储类型 | 是 | minio | 单选 minio / oss，切换后显示对应字段 |

**存储类型 = minio（展示 3 个字段）**

| 页面字段 | 对应字段 | 必填 | 默认值 | 限制 |
|---|---|---|---|---|
| 服务器账号 | AccessKey | 是 | root | 3–20 位，字母、数字、下划线、中划线 |
| 服务器密码 | Secretkey | 是 | Zwhk@2024#A | 8–40 位（minio 要求密码至少 8 位），不能有空格 |
| 素材管理端口 | — | 是 | 9000 | 端口规则 |

minio 不展示的字段（后台按默认值处理）：文件过期时间 36000、存储桶名称 dock、区域 cn-shanghai、网页 Endpoint 地址和端口（取第一步的访问地址和端口）、设备 Endpoint 地址（http:// + 访问地址）、容器 Endpoint 地址 http://minio 和端口 9000。

**存储类型 = oss（展示 9 个字段，默认都为空）**

| 字段 | 必填 | 限制 |
|---|---|---|
| 存储桶名称 | 是 | 3–63 位，小写字母、数字、中划线，必须以小写字母或数字开头和结尾（阿里云规则） |
| EndPoint 地址 | 是 | 域名或 IP，如 oss-cn-shanghai.aliyuncs.com，最长 253 位 |
| EndPoint 地址端口 | 是 | 端口规则，默认 443 |
| CDN 地址 | 否 | 填写时须为 http:// 或 https:// 开头的网址 |
| 角色 ARN | 是 | 格式 acs:ram::账号ID:role/角色名，最长 256 位 |
| 角色会话名称 | 是 | 2–64 位，字母、数字、. @ - _ |
| 区域 | 是 | 如 cn-shanghai，小写字母、数字、中划线，最长 32 位 |
| AccessKeyId | 是 | 16–64 位，字母和数字 |
| AccessKeySecret | 是 | 16–64 位，字母和数字，默认密文 |

oss 不展示的字段：文件过期时间 36000。

## 三、通信服务

提示：该模块配置用于机场上云使用，若是修改，若是重启需要10分钟左右，且机场需要重新设置机场上云方可使用，请谨慎修改。

| 字段 | 必填 | 默认值 | 限制 |
|---|---|---|---|
| mqtt 账户名 | 是 | admin | 不支持修改（一直置灰） |
| mqtt 账户密码 | 是 | 随机生成 8 位 | 见下方 |
| 无人机通讯端口 | 是 | 1883 | 端口规则 |

**mqtt 账户密码**
- 随机生成规则：8 位，字符取自数字 1–9 和字母 A–Z，排除易混字符 1/I、2/Z、8/B、5/S、0/C/G/O/D、H/N/M，必须包含 # 或 @ 等特殊字符。
- 手动修改时：8–16 位，必须包含字母、数字和至少一个特殊字符（# 或 @），不能有空格（已确认）。
- 输入框旁加「重新生成」按钮。

不展示的字段：wssUrl（wss:// + ip + :网页访问端口 + /mqtt）、tcpUrl（tcp:// + 访问域名）、服务内部 tcpUrl 和端口 1883。

## 四、视频服务

提示：该模块用于机场直播使用，若是修改，重启服务需要10分钟左右，请谨慎修改。

| 字段 | 必填 | 默认值 | 限制 |
|---|---|---|---|
| 推流服务端口 | 是 | 11935 | 端口规则（rtmp 协议推流） |
| rtc 拉流端口 | 是 | 18000 | 端口规则 |
| rtsp 拉流端口 | 是 | 11554 | 端口规则（单兵无人机 AI 功能直播） |

不展示的字段：直播服务地址、回放地址、推流服务地址（都取访问域名）及对应端口（取网页访问端口）、flv 拉流端口（和网页访问端口一致，如 443）。密钥、应用名称只支持本地直播服务，页面隐藏。

## 五、时序服务

提示：该服务用于机场调用，若是修改，相对应的机场需要重启才能生效使用，请谨慎修改。

| 字段 | 必填 | 默认值 | 限制 |
|---|---|---|---|
| ntp 服务 | 是 | 按设备当前是否联网判断（已确认）：未联网（内网环境）默认访问地址；已联网（互联网环境）默认 ntp1.aliyun.com | IP 或域名，最长 253 位。要求 ntp 服务能访问通 |

## 六、确认记录

1. 选「内置配置」时：模块默认展开，字段显示对应默认值。
2. 四个模块默认都选「内置配置」。
3. mqtt 密码手动修改：8–16 位，必须含字母、数字和 # 或 @。
4. ntp 内网 / 互联网环境：按设备当前是否联网判断。
5. 不做端口重复校验；点「暂存并下一步」时验证各服务及端口能否连通，不通过按「xx服务链接不上，请检查修改xx服务相关配置。」报错。
